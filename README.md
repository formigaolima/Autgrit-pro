# AUTGRIT — Global AI Super App

AI-driven Super App offering Ride-Hailing, Delivery, Physical/Digital Services, and Sober Driver, featuring AI security and crypto payments.

## Deployment & Hosting

This application is built and hosted using **AI Studio**. 

- **Live Preview**: Your app is available at the "Development App URL" provided in the AI Studio interface.
- **Sharing**: Use the "Share" button in AI Studio to generate a link for others.

## Exporting for Local Development (or GitHub)

If you wish to export this project to GitHub or develop locally, follow these steps:

1. **Export**: Go to **Settings > Export to GitHub** or **Download ZIP**.
2. **Install Dependencies**:
   ```bash
   npm install
   ```
3. **Environment Setup**:
   - Create a `.env.local` file.
   - Set `GEMINI_API_KEY` to your valid Gemini API key.
   - Set `APP_URL` to your local or deployment URL.
4. **Run Development Server**:
   ```bash
   npm run dev
   ```
